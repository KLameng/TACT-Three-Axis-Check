# TACT 三轴坐标检查法

给 AI 系统的错误现象在封闭坐标空间（L 4层 × M 9族 × P 8档 = 288 格）里定位唯一坐标，并给出可执行的验证路径。

## 坐标系三件事（先记住）

三条轴是同一机制的三个侧面，各记一件事，轴与轴不重叠：

- **L 轴（在哪）**：错误发生在系统的哪个环节。L1 模型内部 / L2 输入输出接口 / L3 推理协作链 / L4 系统环境。
- **M 轴（怎么）**：错误以什么形态发生。M1 信息不足 / M2 信息失真 / M3 推理失效 / M4 输出失真 / M5 目标偏移（不含对抗性规避） / M6 外部对抗（含智能体自身对抗、监管规避） / M7 规则-职责-权限体系失配 / M8 系统涌现 / M9 自发协作（母坐标已准入，opts 为空、坐标内容待真实案例 ratified）。
- **P 轴（什么）**：破坏的是哪一面的一致性。P1 事实失真 / P2 逻辑断裂 / P3 完整性缺失 / P4 一致性破坏 / P5 合规越界 / P6 目标偏离 / P7 公平失衡 / P8 安全威胁。

一个**母坐标** = 一个机制族；同一母坐标下可含多个命名子类型（它们是同一机制族的不同具体表现）。判坐标时问的是"**本质是不是这层**"，不是"沾不沾边"——几乎每条错误都跟好几层沾边，沾边就答"是"，会在前面的层被错误截停。

### 母坐标硬分流判据（M 轴内部维度不同，过闸前先分清）

M 轴 9 族混有三种维度：形态（M1-M5）、来源（M6/M9）、系统（M8）、规则体系（M7）。相邻易混族之间设一票否决级判据，命中即改道，不许靠"沾边"停在前面：

- **M5（目标偏移） vs M6（外部对抗）**：三支判定，命中任一即走 M6，全部不中才走 M5——
  1. **攻击面**：事件由外部攻击者主动制造（注入、投毒、凭证利用、供应链攻击等）；
  2. **越权面**：行为涉及未经授权获取/访问/控制/传输外部资源、系统或凭证（自主越权、逃逸、能力提取、未经授权的数据外传）；
  3. **欺骗面**：行为涉及对抗性欺骗（诱导人类做高风险决策、规避检测与监控盲区利用、伪造状态欺骗）。
  以上均不涉及的**纯自主偏离**（答非所问、目标漂移、谄媚、自评失准、语境漂移、约束被降级权衡）→ M5。
- **M6（外部对抗） vs M8（系统涌现）**：判据=**是否存在对抗主体**。有攻击者或智能体自身的对抗性行为→M6；无任何主体、是组合/涌现出来的错误→M8。
- **M5（目标偏移） vs M8（系统涌现）**：判据=**单实体偏离 vs 多组件涌现**。单一系统/模型的行为方向偏离设计意图→M5；多个本正确的部分组合后涌现错误→M8。
- **M7（规则体系失配） vs M5（目标偏移）**：判据=**冲突/失配的来源**。规则、职责或权限体系自身冲突失配（互斥、无归属、越权承接）→M7；体系无冲突、是行为方向被替换/偏离（含约束-目标反转 M5-9）→M5。**C5 反向锚点（v1.1.1，修复 kappa v9 元宝/豆包误判）**：约束被模型**主动降级/权衡为优化目标**（为转化率等牺牲约束）→M5-9；规则/职责/权限**体系自身**互斥、无归属、越权承接→M7。区别：C5 是**执行层选择不守**（体系没问题、行为方向偏），M7 是**体系本身有冲突**（撞上矛盾规则）；"对老客户守约、对新客户绕行误导"→M5-9。
- **M6 vs M9（自发协作）**：判据=**行为性质**。多智能体协作突破访问边界或产生对抗性动作→M6（M6-6）；无对抗动作、仅利用共享资源涌现超出预期的协作行为→M9。**命中 M9 时，按固定落码文案输出：『母坐标 M9 自发协作，子坐标待真实案例 ratified，暂不落子码』，仅 L 轴定位；不编造子码，也不因无子码而判失败。**

### 过闸速查（分流句速览，细则在各坐标 desc）

- 用户诱导绕规但无恶意：归 M6-11（规避行为按对抗面处理，不因"用户非攻击者"改道）。
- 记忆/摘要写入：写入由外部攻击者或恶意注入驱动→M6-4；无攻击者的自主写入（含外部非恶意诱导）→M5-8。
- 群体差异：**先问差异在哪一层**——约束执行层（是否守约束/边界随群体波动，等价情形被区别对待）→M5-9；决策结果层（评分/推荐/建议结果系统性更差）→M2-5。反例防误判："对老客户守约、对新客户绕行误导"看似算法歧视，实为约束执行层差异→M5-9；"推荐系统给某群体系统性更差的结果"才是决策结果层→M2-5。
- 越权：被动承接越权任务、权限校验失守→M7-3；无外部越权指令/无外部攻击指令的自主探测突破（用户合法指令不改变自主突破本质）→M6-6。
- 数据外传：智能体未经授权向外部传输/写入数据→M6-6（越权面含"传输"）；人类用户或工具主动上传、产品默认行为→治理域不占 M/P 码。
- 自利欺骗兼诱导决策：按后果面优先归 M6-5。
- 数据/检索错误：存在投毒意图或攻击者→M6-7/M6-8；无意图的数据或检索错误→M2 族。
- 注入与记忆：指令被即时执行→M6-3；指令/恶意内容写入记忆或摘要、后续持续引用→M6-4；两者同时成立时按三步匹配法双挂列出（即时执行归 M6-3、持久化引用归 M6-4），不强行唯一化。
- 欺骗对象：诱导/操纵人类决策→M6-5；规避监控/规则系统→M6-11；混合场景按最终操纵对象裁决。
- 约束降级：约束权衡服务于非自利任务/业务目标→M5-9；自利驱动（为自身利益钻奖励空子）→M5-5。
- 违反禁令：禁令被直接无视（无规避动作）→M5-2；以变体、盲区、拆分等规避方式违反→M6-11。
- 自评虚高：内部置信/自评信号与正确率失准→M2-3；对外硬接任务、虚报能力、评测伪装→M2-4。
- 约束遗忘：结论被抽离语境过度泛化→M5-6；早期信息/约束在长对话中丢失遗忘→M8-3。
- 格式违约：产出/接口契约类违约（格式、schema、字段）→M4-3/P5-6；行为/任务约束类违反（禁令、规范动作）→M5-2/P5-5。

### 跨轴分流声明

同一事件在 M 轴与 P 轴可独立命中（三轴各记一个侧面，不构成重复计码）。典型示例：自写入驻留指令——M 轴过 **M5-8**（怎么错=目标被静默替换），P 轴过 **P6-4[5]**（破坏什么=目标偏离），两轴独立、互不替代；约束-目标反转——M 轴过 **M5-9**（机制=约束被降级为优化目标），P 轴过 **P7-4**（破坏=公平失衡面）。
轴间分工声明：L 轴问"在哪一层"，M 轴问"怎么错的"，M8 与 L3 语义重叠属分工而非重复——单环节无错、接起来才错的，L 轴过 L3、M 轴过 M8；"矛盾句"输出——逻辑冲突优先 P2-4、事实核验错误过 P1-8、与自身历史不一致过 P4-9；环境迁移失配优先 M1-3/P3-6（机制面），环境本身故障（网络/配额/隔离边界）过 L4。

## 数据文件（执行前必读）

`references/coordinate_data.json` 是本技能唯一数据底座（v2.7.8，117 个精细坐标 / 580 条"表现-定位-验证路径"），结构：

- `L[]`：L 轴 4 层，每层含 `code/name/criterion`（criterion 是判"是否属于本层"的操作判据）。
- `M_groups[]` / `P_groups[]`：M 轴 9 个**母坐标**（M1-M9，其中 M9 母坐标已准入、opts 为空、内容待 ratified）、P 轴 8 个**母坐标**，每组含 `code/name/criterion` 和 `opts[]`（该母坐标下的**子坐标**）。
- 每个子坐标：`code`（如 M3-1）、`name`（机制名）、`desc`（一句话机制描述）、`pairs[]`（每条为三元组，条数因坐标而异）：
  1. **表现**：这个错误在现象上长什么样；
  2. **定位**：错误发生在系统的哪个位置/环节；
  3. **验证路径**（第三段）：去哪个环节、用什么操作做 diff/复现，出现什么判据即判命中。

需要坐标含义、判据、表现、位置、验证路径时，一律读这个文件，不要凭印象编造坐标名或验证方法。

## 三步匹配法（核心执行流程，严格按序）

### 第 0 步：前置排除闸（先排除"不占码"情形，再进 L/M/P）

开始三步匹配法前，先按序检查四类**不占 M/P 码**的情形；命中任一即**先过"防误伤护栏"、再走对应出口**（护栏确认仍应排除后，才不再进入 L/M/P 过闸）；全部不中才进入第 1 步。每类以"主体/本质"锚点判别。**混合场景不整体排除**：现象除排除部分外仍存在真正的模型/系统错误成分时，不整体排除，继续过闸处理剩余部分（对排除部分单独标注）。

| 序 | 情形 | 判别锚点（先问） | 出口 |
|---|---|---|---|
| E1 | **治理域** | 错误的**主体是人**吗——人类把 AI 当工具实施犯罪/攻击（深度伪造诈骗、换脸盗刷等）？注意：**智能体自主**发起的对抗/作恶不在此列，继续过闸 | 治理域，不占 M/P 码 |
| E2 | **环境/基础设施故障（越界声明）** | **是环境坏了**（网络/配额/隔离边界/配置缺陷/AppSec 漏洞/组织治理），还是系统没适配环境（后者 M1-3/P3-6 机制面，继续过闸）？且模型本身未犯错？ | 仅 L4 描述，不占 M/P 码 |
| E3 | **预测格** | 机制**仅 1 例真实案例**且在预测格名单（传感欺骗/输入媒介替换、安全紧急停机/熔断失效）？ | 标预测格，按机制所在 L 层描述，不占正式 M/P 码，不造码 |
| E4 | **评测风险信号** | 只是**倾向/信号**、尚未构成已发生的错误事件（欺骗性升高、对齐倒退、越权倾向）？构成实际错误行为则过闸 | 仅 L1 描述，不占 M/P 码 |

**防误伤护栏（排除前必读）：** 排除闸是**分流引导，不是终审**——命中任一 E 后，先过下列护栏再定出口。核心一条：**疑罪从宽入闸**——拿不准是否该排除时，不排除、放行进过闸，让三步匹配法（而非前置闸）裁决；后续若发现存在真正的系统错误成分，撤销排除、继续过闸。

- **G1 结构性 · 排除可撤销**：排除不豁免复核。命中任一 E 后反问一次："是否存在混合场景 / 环境掩盖系统错 / 智能体自主成分？"任一成立即不放行，对该成分过闸。
- **G2（E1 治理域）双主体分流**：人类纯工具（深度伪造诈骗、换脸盗刷，AI 无自主错）→ 排除；**人类诱导 + 智能体自主执行**绕规/作恶 → 过闸（速查：用户诱导绕规→M6-11、自主越权→M6-6），不因"有人参与"整体排除。
- **G3（E2 环境层）先问系统有无错误成分**：排除前先确认"模型/系统自身是否也有错误行为"；有则不能整体归 L4，对该成分过闸（如隔离边界故障同时暴露智能体自主越权外传 → 过闸 M6-6）。
- **G4（E4 评测信号）倾向 vs 行为判据**：是否已产出**可观察的违规/错误输出**？有 → 过闸；仅倾向/信号 → 排除（仅 L1）。
- **G5（E3 预测格）名单漂移防护**：名单以"边界与纪律"最新文本为准；机制已转正（出现两条互不相干真实案例）→ 不再排除、正常过闸；"传感欺骗/输入媒介替换（预测格）"与"特征扰动 M6-10（正式码）"按"改输入源 vs 改样本表示"分流。

规则定义以"边界与纪律"一节为准，本节为操作化入口；逐条走完后仍判不了是否排除，回到"边界与纪律"核对原文。

### 第 1 步：L 轴选择——按具体问题判断，可单选可多选

逐个读 `L[]` 的 criterion，结合用户描述的**具体问题**判断它错在哪一层：

- 现象明确只发生在一个环节 → 单选一个 L；
- 现象横跨多个环节（如单轮内就犯、且在接口处又放大）→ 可多选，对每个命中的 L 分别完成后面的 M/P 过闸。

#### L 轴操作化判据（v1.0.3 新增，基于 kappa 第四轮 L 轴 63.3% 收敛）

先问**总问题**定位层：这个错是"模型自己单轮内就能犯（不依赖跨轮/外部信息）"，还是"需要读出跨轮/外部信息"，还是"发生在进出边界对接"，还是"环境本身坏了"？再用下表判据落层：

| L 层 | 判定问题 | 锚点 |
|---|---|---|
| L1 模型内部 | 删掉一切外部输入、跨轮记忆、协作单元、环境因素，模型单独一次生成是否仍会犯？ | 单轮、无外部依赖、一次生成里就出 |
| L2 输入输出接口 | 错误是否发生在数据进入/结果离开系统的**边界对接处**（两方符号/字段/规则/约定对不上）？ | 进出边界、格式/符号/约定失配 |
| L3 推理协作链 | 错误是否需要**读出跨轮/外部信息**（RAG、记忆、工具链、长会话、过期文档）参与当前决策，或发生在环节间传递/交接？ | 跨轮/外部读出、多环节组合、单看每环节都对 |
| L4 系统环境 | 错误是否源于运行环境本身（网络、配额、隔离边界）而非模型行为？ | 环境坏、模型没犯错 |

**关键边界速查（二选一即可落层）**：
- **L1 vs L3**：是否需要读出跨轮/外部信息参与当前决策？是→L3；否→L1。
- **L1 vs L2**：单次生成内部就能犯（不涉进出边界对接）→L1；错误在进出边界对接（格式/符号/约定）→L2。
- **L2 vs L3**：错误在单轮进出接口的对接→L2；在跨轮/跨环节的传递与组合→L3。
- **L3 vs L4**：故障源在模型/推理链可修复范围内→L3；在基础设施且与模型推理无逻辑关联→L4。

**L 轴来源判定总则（v1.1.1 新增，基于 kappa v9 C6 反向约束误伤修复）**：

落层前先问**错误来源**：这个错是"模型自身单轮自发产生"，还是"对抗性外部输入 / 跨轮信息驱动"？

- 错误来源在**模型内部自发**（无外部指令/注入/跨轮读出，模型单轮决策即出）→ 优先判 L1；
- **提示注入等对抗性外部输入驱动的错误**（恶意指令覆盖系统提示、夹带指令被当真执行）→ **不适用"单轮自发"豁免**——来源在输入边界而非模型内部，按锋利判据判 **L2**（错误在数据进入系统的边界对接处触发）；
- 需要**读出跨轮/外部信息**参与当前决策（RAG、记忆、工具链、长会话、过期文档）→ L3；
- 环境本身故障致模型失守、模型未犯错 → L4。

**自主越权特殊锚点（C2，v1.1.1，防腐版）**：
- 越权**决策**由模型内部自发产生（无外部指令/攻击者）→ **必选 L1**；
- 若越权**必须依赖跨环节/工具链才能完成**，且该环节本身有错或失配（如某环节把越权指令当正常任务承接）→ **追加 L3**；
- 若越权单轮即可完成（模型直接输出越权结果，无跨环节依赖）→ **不追加 L3**；
- **绝不因"环境遗留密钥/凭证"选 L4**（模型主动利用、环境未使其失守；L4 只在环境故障让模型失守时成立）。

> 注：C1/C2/C3/C7（投毒、越权、诱导、规避）的 L golden 已按 v1.1.1 操作化判据对齐——C1→L3（跨环节读出）、C2→L1（越权决策在模型内部）、C3→L1（单轮自发话术）、C7→L1（单轮自发规避），与 v9 验证五家收敛一致。

### 第 2 步：M、P 轴——三步匹配法依次过闸

M 轴和 P 轴**各自独立**走一遍下面的流程（顺序固定：先 M 后 P，母坐标排队顺序 M1→M9 / P1→P8 不许跳）：

1. **先走母坐标，再走子坐标。** 沿 M1→M2→…→M9（P1→P2→…→P8）逐组过母坐标闸；母坐标判"是"后，才进入该组 `opts[]`，再从第一个子坐标开始依次过子坐标闸。判"否"才允许走到下一个。
2. **每个坐标前必问"是否"。** 走到哪个坐标（无论母坐标还是子坐标），就对着它的 criterion / desc / pairs 表现问一次"本质是不是这一层/这一条"，每层只有"是/否"两个选项。
3. **反问验证：无论回答"是"还是"否"，都严格反问一次，看能否推翻结论。**
   - 答"是"→ 反问："有没有一条一票否决级的硬反例，能证明它本质不是这条？"（攻不死才保留）
   - 答"否"→ 反问："它的机制其实是不是落在这里？是不是因为只看了表面后果、没看机制，才误判为否？"
   - 支持性证据廉价（沾边证据每条错误都有），要找的是**机制层面**的硬反例，不是找别扭。
4. **走完全程才定结果，不提前锁定。** 即使前面某坐标很像命中，也必须把整条轴问完，防止漏判后面更本质的坐标；最终保留所有通过反问、攻不死的命中坐标（同一轴可命中多个子坐标，分别列出，不强行并成一个）。

### 第 3 步：结合第 1、2 步给出总体结论

把命中的 L 与 M、P 组合成完整坐标（如 L2/M3/P1），按下述输出格式成稿。

## 输出结论格式（五项必须齐全）

结论必须包含：

1. **三维坐标名称**：完整坐标（如 L2/M3/P5）+ 三个母坐标名（如"输入输出接口 · 推理失效 · 合规越界"）；
2. **命中的 L 轴坐标**：L 坐标编号与名称，并说明为什么是这一层（引用 criterion）；L 多选时逐个说明；
3. **所有最终命中的子坐标**，每一个都给出四件事：
   - **含义**：子坐标 code + 机制名 + desc；
   - **可能表现**：从该码 pairs 中选取与用户现象最贴合的 1~3 条"表现"原文（可多条）；
   - **发生位置**：对应"定位"（pairs 第二段）；
   - **验证路径**：对应第三段"验证路径"，照原文给出可操作判据，不改写、不自造；
4. **反问留痕**：简述在母坐标/子坐标闸上被反问推翻或差点误判的点，说明为什么最终落在该坐标（体现坐标唯一性）；
5. 若整条轴走完都判不了，不要硬塞：说明现有 117 个精细坐标装不下，并按"是否一个独立且唯一机制、是否有两条互不相干错误同属此机制"给出是否应新增层的判断，交用户决定，不自行造码。

## 边界与纪律

- 只做定位与验证路径说明，不给"系统一定存在该漏洞/已被攻破"之类的最终断言；输出面向用户时附"智能分析结果，仅供参考"。
- 验证路径用于在**自有环境、自有模型、自有靶场**上复现核验；涉及主动构造攻击（注入、逃逸、投毒类）时提示仅限授权的自有测试系统，不得对第三方真实系统发起。
- 子坐标同名不等于同一条：以 code 和所属母坐标为准（如 M3-1 与 P1-3 机制相近但坐标侧面不同）。
- 数据以 `references/coordinate_data.json` 为准；命中后把 pairs 原文作为依据，禁止凭训练记忆补造表现或验证步骤。
- **越界声明**：配置缺陷、基础设施故障、传统软件/AppSec 漏洞、组织治理（授权范围、平台策略、版权授权争议）等"系统本身没有犯错"的事故不在分类范围——TACT 是错误分类学，不是事故分类学；这类现象仅落在 L4 环境层描述，不新增 M/P 坐标。合法服务被用作非法信道（信道用途劫持）是"凭证失守+治理缺陷"的组合表现，拆解归 M4-2 凭证泄露与治理声明，不单列坐标。人类攻击者使用 AI 工具实施犯罪/攻击（深度伪造诈骗、换脸盗刷等）属治理域，不占 M/P 码。
- **M6-10 边界封堵**：文本域对抗后缀（GCG 类，同现"表示层微扰"与"语义层注入"）一律归 M6-3 提示注入；M6-10 特征扰动只管多模态/物理域扰动（像素、特征、物理贴纸、音频），两坐标按"语义层 vs 表示层"分流，不重叠。
- **预测格**：仅 1 例真实案例的机制（当前如传感欺骗/输入媒介替换、安全紧急停机/熔断失效）保持预测格状态，不占正式子坐标编号；待出现两条互不相干的真实案例后按演进规则转正，不自行造码。
- **评测风险信号**：模型在评测中暴露的倾向（如欺骗性升高、对齐倒退、越权倾向）未构成已发生的错误事件时，仅 L1 层描述，不占 M/P 码；构成实际错误行为后才按三步匹配法过闸。
- **镜像与对称**：三轴各记一个侧面，同一机制在 M/P 两轴双挂是设计特性（M 判怎么错、P 判破坏什么），不是重复坐标。主要镜像对照：M6-1≙P8-8 供应链、M6-2≙P8-9 凭证泄露、M6-3≙P6-4 提示注入、M6-5≙P8-5 人-智能体信任利用、M6-6≙P8-4 沙箱逃逸（近似，非精确同名镜像；P 面按现象归：逃出沙箱→P8-4、权限扩大承接→P5-2、都不贴→留空待核）、M6-11≙P8-7 监管规避、M5-9≙P7-4 约束-目标反转、M5-8≙P6-4[5] 自生成驻留指令、M4-2≙P8-3 凭证泄露、M4-3≙P5-6 规约违约。判坐标时先问"本质是不是这层"（母坐标 criterion），镜像对不互相抢占：同一事件 M 轴命中与 P 轴命中独立保留。**新增坐标不强制补镜像**——只有出现真实案例证明该机制的 P 侧（或 M 侧）表现独立成立时才补，不为了"对称好看"造镜像条。
